# PRISM-AI — оглавление плана разработки

PRISM-AI — самостоятельная recruiting CRM/ATS: приложение ведёт вакансии, базу кандидатов и резюме, заявки и этапы отбора, историю контактов и задачи рекрутера. В нём есть собственная локальная база, интерфейс, ИИ-прогнозы, аналитика и графики. Открытые датасеты используются для анализа источников и задач, а собственная многоцелевая нейросеть обучается и проверяется на созданном по профилям источников синтетическом датасете. Cloudflare Workers AI объясняет готовые результаты, hh.ru предоставляет поиск рыночных вакансий; HRMS-коннектор является дополнительным экспортным модулем. Приложение полностью работает без внешней HRMS.

Это краткое оглавление. Исполняемая инструкция, источники и правила сборки датасетов, формулы, конфигурации обучения, требования к интерфейсу, приёмка, macOS-сборка и контрольные коммиты находятся в [полном плане разработки](./DEVELOPMENT_PLAN.md). Порядок работ фиксирован: данные → собственный датасет → модели → приложение и интеграции → приёмка и выпуск → техническая документация последней.
